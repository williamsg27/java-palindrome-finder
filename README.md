# java-palindrome-finder
Java program that identifies palindromes from a text file using recursion, string manipulation, file I/O, and exception handling.

## Features

- Reads words from a text file
- Checks each word to determine whether it is a palindrome
- Uses recursion to evaluate words
- Writes identified palindromes to an output file
- Handles file-related exceptions
- Processes words using string manipulation

## How It Works

The program reads each word from `wordList.txt` and checks whether the word reads the same forward and backward.

For example:

```text
racecar → Palindrome
level → Palindrome
computer → Not a palindrome
